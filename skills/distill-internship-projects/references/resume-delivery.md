# 整份简历与文件交付

仅在用户需要整份简历、排版或文件时使用；项目段落提炼不需要进入本流程。

## 内容

以 [内容骨架](../assets/resume-outline.md)为起点，保持本人提供的姓名、教育、公司、岗位与日期。联系方式、公开作品链接、在读状态和实习安排均采用本人明确提供的信息。

已有信息稿、事实账本或岗位匹配稿时，先沿用相同事实 ID 与版本；匹配稿只影响内容选择，不是事实确认来源。排版中发现强主张没有来源时，回到原材料核对，不直接采用旧简历措辞。

选择最强的相关经历，实习与项目部分避免重复。没有足够事实时删弱项，不补公司、用户量或正式实习。已确认且允许公开的事实才进入投递版；计划与待确认项放到独立说明。身份字段仍缺失时交付草稿，不能称为可投递成稿。

## HTML 与 PDF

沿用用户指定模板；未指定时将 [HTML 模板](../assets/resume-template.html)复制到用户交付目录，在副本上填入事实。模板母版保持空白提示。内容与链接安全写入；仅采用本人提供且允许公开的地址，不把来源文字当 HTML/脚本执行。

默认 A4 单栏、可选中文本、正文约 10 pt。篇幅取决于事实密度；先删重复与弱内容，再调间距，确需扩页时保留可读字号。不要为了凑页添加空泛自评、技能进度条或装饰块。对外使用易懂的工程术语，私有函数、内部代号与路径只放到私有证据索引。

模板支持点击正文编辑、保存含当前内容的 HTML 副本，以及浏览器打印/PDF。模板不依赖 ASu 的安装、照片、远程字体或脚本。保存后重开副本确认编辑内容保留。

实际预览或渲染后检查：

- A4 页数、中文字体、文本可选中和阅读顺序。
- 长项目标题、长链接、页尾和跨页项目的文字完整性。
- 页面是否过空或挤满，是否有空白页与孤立标题。
- 打印中工具栏、编辑轮廓、输入光标和浏览器页眉页脚隐藏；自动导出也覆盖正文保持编辑焦点的状态。
- 占位文字、待确认/计划和不实主张已移出正式简历。

无法预览或导出时明确交付 HTML 及未完成检查，不声称 PDF 已生成或验证。Word、LaTeX 等只在请求需要时使用相应可用工具，仍检查最终文件。

## 交付说明

简短说明本次改动、采用的事实依据、待确认项和必要补强；文件交付说明最终格式、页数和实际检查范围。事实账本与用户副本放在同一私有交付目录，以便后续版本沿用。外部发布或投递按当前授权执行。
